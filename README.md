## 当前工作流：一份英语原文 × 五张配图 × 多个语种

1. 在「01 内容素材」输入唯一的共用英语源文案，自动用于五张素材。
2. 五张素材各自上传顶部图片、调整缩放/位置/区域高度和版式；卡片不再单独输入文案。
3. 在「03 多语种」勾选目标语言并生成。每种语言只调用一次翻译接口，成功译文同步到全部五张素材。已有译文复用，修改源文案清除全部旧译文。
4. 勾选参与导出的素材、目标语言和是否包含英语，批量导出。5 张 × 3 种导出语言 = 15 张；如另含英语则 20 张。

项目保存为 v3，包含共用源文案与五素材图片/版式。兼容原文一致的旧项目；原文不一致的旧项目会提示拆分，不会静默覆盖文案。原有旧项目文件不修改。

验证：共用原文同步、旧译文失效、每语言单次调用、成功译文复用、图片与版式独立、15 张/12 张导出组合测试通过；DeepL/通用接口自动切换测试通过。真实 API 翻译仍需用户配置密钥验证。

## DeepL 与通用接口自动切换（当前版本）

默认启动入口已改回本地服务版，以支持 DeepL 转发；双击「启动HN爆单出品.command」，或访问 http://127.0.0.1:8765/?v=deepl2 。服务只监听本机地址。单文件 HTML 仍可离线编辑和导出，翻译只支持通用接口，DeepL 需使用服务版。

侧栏「翻译接口」分别配置 DeepL Key 与原通用接口。只配置一个时自动使用该接口；同时配置时按所选优先级调用，失败自动尝试另一个。同一批次优先沿用成功接口。密钥无效、额度耗尽或限流时本批次跳过该接口，下一次点击翻译重新尝试。已有译文不会重复翻译，失败条目会列出并可重试补齐。界面显示实际使用接口。

DeepL 自动识别 :fx 后缀的 Free 密钥，也支持手动选择 Free / Pro。密钥只保存在页面内存，转发服务不保存密钥或文案。通用接口仍由浏览器直接请求，须支持 CORS。故障切换可能向两个已配置服务发送同一文案，超时情况下可能分别计费。

验证：双向故障切换、单接口使用、配额跳过、沿用成功接口、异常返回与 DeepL Free/Pro 路由、语言参数映射测试均通过；本地健康检查和跨站请求拒绝已验证。配置面板已做浏览器检查。尚未填入真实密钥，未做付费 API 实际翻译验证。

## 五素材同时编辑

页面上方提供五张独立素材卡，每张可以单独替换图片、编辑英语文案、勾选是否参与生产。也可一次选择最多五张图片，按顺序替换素材 1–5。点击「精调」进入该素材的详细版式设置。

- 默认开启「文案自适应图片高度」：短文案增大画面，长文案缩小画面。图片占画布高度的 15%–75%，翻译后按每种语言长度分别计算。
- 手动拖动图片占比滑杆会关闭该素材的自动模式；可重新勾选恢复自动。
- 五个素材分别保存输出尺寸、裁切位置、图片高度、字号、字体、边距和颜色。不会相互覆盖。
- 文案过长时继续缩小字号，低于可读阈值仍放不下会阻止导出。

## 多语种生产

在「03 多语种」勾选目标语言，可选择是否包含英语原版。配置接口后，点击「为已选素材生成多语种」，会为勾选素材补齐目标语言。也可通过「精调」切换素材后手动填写、校对译文。修改英语原文后，该素材旧译文会清除。

接口须支持 HTTPS、Chat Completions 请求/响应结构与浏览器 CORS。填写完整接口 URL、模型名及密钥。密钥仅存在页面内存，不写入项目；文案发至用户指定服务，可能产生费用。真实接口仍待用户配置与联调。

批量 ZIP 按「已选素材数 × 已选语言数」输出，图片、文案按素材配对。示例：5 个素材 × 3 种语言 = 15 张 PNG。命名为 material-1_es.png 等。缺失图片、文案或排版溢出时会阻止整包导出。

保存项目包含五张素材独立图片、文案、译文与版式，导入可继续编辑。兼容旧版项目并按素材顺序迁移为五素材。关闭页面前请保存。

## 实时预览拖拽

- 在预览的图片区域按住拖动，调整图片位置。图片保持铺满区域，移动范围受图片边界限制；需要更大移动空间可先放大。
- 拖动右下角绿色手柄缩放，或使用「缩放」滑杆、图片区域内的鼠标滚轮（100%–400%）。

- 每个素材独立保存缩放和位置。保存/导入项目以及 PNG、ZIP 导出沿用这些设置；编辑边框与手柄不会进入导出图片。多语言自动高度模式按译文长度适配区域，并沿用缩放与相对位置。
